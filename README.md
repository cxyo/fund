# 基金温度表

一个简洁的基金温度查询网站，帮助您快速了解各类指数基金的温度（估值）状态。

## 功能特性

### 数据展示
- **分类展示**：按大盘、小盘、策略、行业、主题、海外、债券七大类别展示指数基金
- **温度计算**：基于PE/PB分位点计算温度，高温（绿色）表示高估，低温（红色）表示低估
- **涨跌幅显示**：展示年度涨跌幅、今日涨跌幅、上两日涨跌幅
- **关注度指标**：显示基金的关注热度
- **历史温度图表**：点击任意指数的温度数值，可查看该指数的历史温度变化趋势图（使用ECharts实现）

### 精选推荐
每个类别精选温度最低的优质基金排在前面：
- **大盘(B)、小盘(C)、海外(G)**：各精选1个温度最低的基金
- **策略(D)、行业(E)、主题(F)、债券(H)**：各精选2个温度最低的基金
- **精选标记**：精选基金带有 ⭐ 标记，金色边框高亮显示

### 搜索功能
支持按指数代码或名称搜索，快速定位目标基金。

### 数据上传
支持单按钮上传CSV文件，系统自动按日期命名（YYYY-MM-DD.csv），支持非交易日验证。

### 配置管理
支持导出、导入、清除自定义指数配置。

## 使用方法

### 本地运行

```bash
cd D:\AI_CODE_project\DEMO\fund-main
python -m http.server 8000
```

访问 http://localhost:8000

### 上传数据文件

数据上传区域位于页面底部，支持单按钮上传最新数据：

1. 点击「📁 选择并上传数据文件」按钮
2. 选择包含最新指数数据的CSV文件
3. 系统自动按日期命名（YYYY-MM-DD.csv）并保存
4. 自动更新页面显示的基金温度数据

**重要提示**：
- 系统仅支持在交易日（周一至周五）上传数据
- 上传的CSV文件将被自动命名为当天日期格式（如2026-01-06.csv）
- 历史数据文件需保持在项目根目录，系统会自动加载所有日期命名的CSV文件用于生成历史温度图表
- 系统会自动根据实际数据文件日期显示数据，当天数据未上传时自动显示前一天数据
- 例如：今天是1月7日，晚上7点前数据未上传时，系统显示1月6日的数据，数据日期也显示为1月6日

### 添加自定义指数

1. 在顶部搜索框输入指数代码或名称
2. 按回车键搜索
3. 从搜索结果中选择目标指数
4. 选择所属类别（大盘/小盘/策略/行业/主题/海外/债券）
5. 点击「添加」按钮

### 导出配置

点击「📥 导出配置」按钮，系统将下载当前所有自定义指数配置（jj-config.json 文件）。

### 导入配置

1. 点击「📤 导入配置」区域的「选择配置文件」按钮
2. 选择 JSON 格式的配置文件
3. 系统自动导入并合并配置
4. 显示导入结果统计

### 清除配置

点击「🗑️ 清除配置」按钮，可清空所有自定义配置和已上传数据，页面将显示空表格。

## 数据文件说明

### 日期命名CSV文件 (YYYY-MM-DD.csv)

系统使用日期命名的CSV文件存储基金数据，如 `2026-01-06.csv`。每个文件包含该日期的所有指数数据，格式如下：

| 字段 | 说明 |
|------|------|
| code | 指数代码 |
| name | 指数名称 |
| date | 日期 |
| change_pct | 涨跌幅 |
| close | 收盘价 |
| pe_ttm | 市盈率 |
| pe_ttm_pct | PE分位点 |
| pb | 市净率 |
| pb_pct | PB分位点 |
| dividend | 股息率 |
| roe | ROE |
| market_cap | 市值 |
| turnover | 成交额 |
| ... | 其他指标 |

**重要说明**：
- 系统会自动加载所有日期命名的CSV文件
- 最新数据由文件名日期最新的文件提供
- 历史文件用于生成指数的历史温度变化图表

### code.json
指数代码配置，定义各类别显示的指数列表：

```json
{
  "B": ["399006", "399550"],
  "C": ["399673", "000852"],
  "D": ["399348", "399701"],
  "E": ["399807", "399396"],
  "F": ["930653", "399997"],
  "G": ["HSCGSI", "HSTECH"]
}
```

## 温度颜色说明

| 温度范围 | 颜色 | 含义 |
|---------|------|------|
| ≥50°C | 绿色 | 高温区域，估值较高 |
| 30-50°C | 黄色 | 正常区域，估值适中 |
| <30°C | 红色 | 低温区域，估值较低 |
