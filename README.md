# 基金温度表

一个简洁的基金温度查询网站，帮助您快速了解各类指数基金的温度（估值）状态。

## 功能特性

### 📊 数据展示
- **分类展示**：按大盘、小盘、策略、行业、主题、海外、债券七大类别展示指数基金
- **温度计算**：基于PE/PB分位点计算温度，高温（绿色）表示高估，低温（红色）表示低估
- **涨跌幅显示**：展示年度涨跌幅、今日涨跌幅、上两日涨跌幅
- **关注度指标**：显示基金的关注热度

### ⭐ 精选推荐
每个类别精选温度最低的优质基金排在前面：
- **大盘(B)、小盘(C)、海外(G)**：各精选1个温度最低的基金
- **策略(D)、行业(E)、主题(F)、债券(H)**：各精选2个温度最低的基金
- **精选标记**：精选基金带有 ⭐ 标记，金色边框高亮显示

### 🔍 搜索功能
- 支持按指数代码或名称搜索
- 快速定位目标基金

### 📁 数据管理
- **CSV上传**：支持上传CSV文件更新基金数据
- **配置导出**：导出当前配置为JSON文件
- **配置导入**：导入外部配置，覆盖或合并现有配置
- **自动下载**：上传CSV后自动下载标准格式的data.csv文件

## 使用方法

### 1. 本地运行

```bash
# 进入项目目录
cd D:\AI_CODE_project\DEMO\jjwd

# 启动本地服务器
python -m http.server 8080
```

然后访问：http://localhost:8080

### 2. 上传CSV数据

1. 点击"选择CSV文件"按钮
2. 选择包含指数数据的CSV文件
3. 系统会自动解析并更新数据
4. 提示下载新的data.csv文件，保存到项目根目录

### 3. 添加自定义指数

1. 在搜索框输入指数代码或名称
2. 按回车键搜索
3. 从结果中选择目标指数
4. 选择所属类别
5. 点击"添加"按钮

### 4. 导出/导入配置

- **导出配置**：点击"导出配置"下载当前配置（jj-config.json）
- **导入配置**：点击"选择配置文件"上传JSON格式的配置

## 数据文件说明

### data.csv
主数据文件，包含以下字段：
| 字段 | 说明 |
|------|------|
| 代码 | 指数代码 |
| 名称 | 指数名称 |
| PE-TTM | 市盈率 |
| PE-TTM(分位点%) | PE历史分位点 |
| PB | 市净率 |
| PB(分位点%) | PB历史分位点 |
| 年度涨跌幅 | 年度涨幅百分比 |
| 今日涨跌幅 | 当日涨跌幅 |
| 关注度 | 雪球关注人数 |

### old_data.csv
历史数据文件，用于获取上两日涨跌幅数据。

### code.json
指数代码配置，定义各类别显示的指数列表。

## 温度颜色说明

| 温度范围 | 颜色 | 含义 |
|---------|------|------|
| ≥50°C | 🟢 绿色 | 高温区域，估值较高 |
| 30-50°C | 🟡 黄色 | 正常区域，估值适中 |
| <30°C | 🔴 红色 | 低温区域，估值较低 |
