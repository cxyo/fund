# 基金温度表 - 使用说明

## 📊 简介

基金温度表是一个用于辅助指数投资的参考工具，通过PE和PB分位点计算指数的"温度"，帮助投资者了解当前市场估值水平。

## 🌡️ 温度说明

| 温度范围 | 颜色 | 含义 | 操作建议 |
|---------|------|------|---------|
| ≥50°C | 🟢 绿色 | 高温 | 市场偏贵，考虑分批卖出 |
| 30-50°C | 🟡 黄色 | 正常 | 市场正常区间，持有观望 |
| <30°C | 🔴 红色 | 低温 | 市场便宜，可以投资 |

## ⭐ 温度星级

系统会计算中证全指(000985)的温度星级作为整体市场参考：

- **1星**：市场很贵，不易入市
- **2星**：市场偏贵，分批卖出
- **3星**：市场正常，正常持有
- **4星**：市场便宜，可以投资
- **5星**：市场最便宜，投资机会最大
- **6星**：历史上还未出现过

## 📈 功能说明

### 添加指数到基金温度表

1. **搜索指数**：在搜索框输入指数代码或名称（如：`000016`、`上证50`、`银行`）
2. **选择指数**：从搜索结果中选择目标指数
3. **选择类别**：根据指数类型选择对应类别
   - **B - 大盘**：权重20%，最多1支
   - **C - 小盘**：权重20%，最多1支
   - **D - 策略**：权重10%，最多2支
   - **E - 行业**：权重10%，最多2支
   - **F - 主题**：权重10%，最多2支
   - **G - 海外**：权重10%，最多1支
   - **H - 债券**：权重20%，最多2支
4. **添加到表格**：点击"添加到基金温度"按钮

### 表格字段说明

| 字段 | 说明 |
|------|------|
| 类型 | 指数所属类别 |
| 总占比 | 该类别在组合中的占比权重 |
| 最大支数 | 该类别最多可持有的基金数量 |
| 指数代码 | 指数的唯一代码 |
| 指数名称 | 指数的名称 |
| 基金温度 | 指数的估值温度 |
| 今年涨跌 | 指数本年度涨跌幅 |
| 上一日涨跌 | 指数前一交易日涨跌幅 |
| 上两日涨跌 | 指数前两交易日涨跌幅 |
| 关注度 | 指数的关注热度指标 |

### 涨跌颜色规则

- **上涨（>0%）**：🔴 红色字体
- **下跌（<0%）**：🟢 绿色字体
- **关注度 > 10000**：🔴 红色字体
